# Minimal DynamoDB table example

This example creates a DynamoDB table with a hash key and TTL using the root module from `examples/minimal/main.tf`.

The repository Makefile generates `provider.tf` when you run `make lint` or `make test` from the repository root. Sign in to AWS first.
